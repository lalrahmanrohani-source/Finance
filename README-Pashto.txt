LAL FINANCE — PWA v7 (GitHub Pages)

دا د LAL Finance بشپړ ویب اپلیکیشن دی چې د GitHub Pages د /Finance/ مسیر لپاره برابر شوی.

فایلونه:
- index.html: اصلي مالي سیستم
- manifest.webmanifest: د Chrome/PWA نصب معلومات
- sw.js: Offline cache او service worker
- icons/: د اپلیکیشن آیکنونه

د GitHub د پورته کولو طریقه:
1) ZIP Extract کړئ.
2) د ZIP دننه ټول فایلونه او icons فولډر د Repository په اصلي Root کې Upload کړئ.
3) Commit changes وکړئ او GitHub Pages ته د خپرېدو وخت ورکړئ.
4) په Chrome کې https://lalrahmanrohani-source.github.io/Finance/ خلاص کړئ.
5) Chrome menu (⋮) کې Install app یا Add to Home screen وټاکئ.

مهم:
- دا ZIP APK نه دی؛ PWA ویب اپلیکیشن دی.
- د سیستم موجوده localStorage data key (finance_ledger_v3) او د پاسورډ key نه دي بدل شوي.
- د ZIP اپلوډ کول پخپله د موبایل موجوده معلومات نه انتقالوي.
- د پخوانیو مالي معلوماتو Backup وساتئ.
- دا فایلونه د /Finance/ GitHub Pages مسیر لپاره دي، بل مسیر ته یې بې له تعدیله مه انتقالوئ.
