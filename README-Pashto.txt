د LAL Finance Management System د اپډېټ نصبولو لارښود

۱) لومړی په پخواني سیستم کې Settings ته لاړ شئ او Download Backup واخلئ.
۲) ZIP فایل Extract کړئ.
۳) د ZIP دننه د Finance 4 فولډر ټول فایلونه (index.html, manifest.json, sw.js او icon فایلونه) د GitHub repository اصلي root ته Upload کړئ؛ یوازې ZIP مه Upload کوئ.
۴) که GitHub د پخوانیو فایلونو د Replace کولو پوښتنه وکړي، هماغه نوم لرونکي فایلونه Replace کړئ. نور فایلونه مه حذفوئ.
۵) GitHub Pages ته څو شېبې وخت ورکړئ، بیا په Chrome کې پاڼه Refresh کړئ.
۶) د معلوماتو د خوندي کولو لپاره د نوي اپډېټ له کتلو مخکې Backup وساتئ.

یادونه: د ډیټابېس کلید finance_ledger_v3 ساتل شوی. د اپډېټ فایل د پخوانیو معلوماتو د حذفولو امر نه لري. د نصب بریالیتوب باید په خپل Chrome کې وازمویل شي.
