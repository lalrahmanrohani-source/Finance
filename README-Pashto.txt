لال فایننس — د GitHub Pages لپاره نوی موبایل اپ (v3)

مهم: ZIP فایل مستقیم مه پورته کوئ؛ لومړی یې Extract کړئ.

۱) په GitHub کې نوی Repository جوړ کړئ.
۲) د ZIP ټول فایلونه او د icons فولډر په Repository کې اصلي Root ته Upload کړئ.
۳) په اصلي صفحه کې باید index.html، manifest.webmanifest، sw.js او icons فولډر ښکاره وي.
۴) Settings → Pages ته لاړ شئ. Deploy from a branch وټاکئ؛ Branch = main او Folder = /(root) وټاکئ، بیا Save کړئ.
۵) د GitHub Pages HTTPS لینک په Chrome کې خلاص کړئ. لومړی ځل ۳۰ تر ۶۰ ثانیو پورې آنلاین پرېږدئ.
۶) د Chrome له درې نقطو (⋮) څخه Install app وټاکئ.

لومړنی پاسورډ: 123456
د پاسورډ بدلول: Sign In → Settings → Change Password.

احتیاط: د موبایل معلومات په همدې براوزر کې ساتل کېږي. د موبایل بدلولو یا د Browser Data پاکولو مخکې Settings → Download Backup وکاروئ.

یادونه: ZIP مستقیم په موبایل کې نه نصبېږي؛ باید فایلونه GitHub Pages ته پورته او د HTTPS لینک خلاص شي.
